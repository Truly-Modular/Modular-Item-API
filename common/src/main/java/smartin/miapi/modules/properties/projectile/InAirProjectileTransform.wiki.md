# Projectile Render Transform
@header Projectile Render Transform
@path /data_types/properties/projectile/transform

Simply transforms the projectiles visuals
```json
{
    "projectile_transform": {
                "rotation": {
                    "x": 0,
                    "y": 180,
                    "z": 60
                },
                "translation": {
                    "x": 0,
                    "y": 0,
                    "z": 0
                },
                "scale": {
                    "x": 1,
                    "y": 1,
                    "z": 1
                }
    }
}
```
