# Module Stats Property

## Description

 The ModuleStats property allows for the specification of various statistics associated with a module, where each statistic  
is represented by a key-value pair.This property is integrated with the Stat Resolver and can be queried by using [module.custom_stat_name].cost refers to the module cost [module.cost]and [module.attribute.minecraft:generic.attack_damage] can be used to refer to the *Modules* attack damage attributesIf you want to adjust attributes based on other attributes we heavily recommend the attribute split property instead,as using this can cause circular dependencies in the math.
