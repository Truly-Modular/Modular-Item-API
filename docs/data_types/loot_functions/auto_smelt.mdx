# Auto Smelt Loot Function

## Description

The `AutoSmeltFunction` is a loot function that automatically smelts a dropped item when the tool used to obtain it has the `auto_smelt` property. When the loot context contains a tool with the `auto_smelt` property, this function looks up the corresponding smelting recipe for the dropped item and replaces it with the smelted result. If no smelting recipe exists for the item, the original drop is returned unchanged. Its full ID is ```"miapi:auto_smelt"```

## Data

This loot function has no configurable parameters.
