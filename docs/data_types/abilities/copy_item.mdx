# Copy Item Ability

## Description

The **Copy Item Ability** allows a modular item to behave exactly like another item. When activated, it mimics the right-click behavior, animations, and usage duration of the target item.This is useful for replicating functionality from vanilla or custom items while still using the modular item system.---### Behavior- When right-clicked, the modular item performs the same actions as the target item it is mimicking.- All interactions (e.g., block use, entity use, item finish, ticking) are delegated to the target item.- The copied item must be specified by its item ID (`id` field).- Optionally, the `fake_item_identity` flag can be used to preserve the target item's identity after use.  **Warning**  many items have issues with this type of ability copy, since the ability is still being executed by the modular item!---### JSON Context Fields- **`id`** _(string, resource location)_:    The item ID of the target item to copy. This must be a valid item registered in the game.    Example: `"minecraft:flint_and_steel"`, `"modid:custom_tool"`- **`fake_item_identity`** _(boolean, optional, default = false)_:    If true, the modular item will pretend to be the target item during use.  This should be well tested if needed, as item to item this might cause no issues, crash the game or conver the item in hand to the target item- **`cooldown`** _(number, optional, default = 0)_:    Time in ticks before the ability can be used again.- **`min_hold`** _(number, optional, default = 0)_:    Minimum time in ticks the item must be held before the copy activates.---### Example```json{	"ability_context": [		{			"id": "addon:test",			"type": "miapi:copy_item",			"priority": 0,			"data": {				"id": "minecraft:flint_and_steel",				"cooldown": 100			}		},		{			"id": "addon:copy_bow",			"type": "miapi:copy_item",			"priority": 1,			"data": {				"id": "minecraft:bow",				"fake_item_identity": true			}		}	]}```This configuration:- Makes the modular item behave like a vanilla flint and steel.- Makes another modular item behave like a bow, preserving the bow's identity after use.
