# Copy Item Ability

## Description

The **Copy Item Ability** allows a modular item to behave exactly like another item. When activated, it mimics the right-click behavior, animations, and usage duration of the target item.This is useful for replicating functionality from vanilla or custom items while still using the modular item system.---### Behavior- When right-clicked, the modular item performs the same actions as the target item it is mimicking.- All interactions (e.g., block use, entity use, item finish, ticking) are delegated to the target item.- The copied item must be specified by its item ID (`id` field).**Warning**many items have issues with this type of ability copy, since the ability is still being executed by the modular item!---### Fields- **`id`** *(string, resource location)*:    The item ID of the target item to copy. This must be a valid item registered in the game.    Example: `"minecraft:flint_and_steel"`, `"modid:custom_tool"`---### Example```json{  "ability_context": [    {      "id": "addon:test",      "type": "miapi:copy_item",      "priority": 0,      "data": {        "id": "minecraft:flint_and_steel",        "cooldown": 100      }    }  ]}```This configuration:- Makes the modular item behave like a vanilla bow,- Triggers bow behavior, including charging and firing, when used.
