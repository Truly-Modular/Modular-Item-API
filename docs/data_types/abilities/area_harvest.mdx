# Area Harvest Ability

## Description

The `area_harvest_ability` allows automatic harvesting and replanting of fully-grown crops in a square area centered on the targeted crop block.This ability uses the **default fields** (`cooldown`, `min_hold`, `max_hold`) and supports one additional custom field:#### Fields- **`range`** *(resolvable double)*:    Defines the radius (in blocks) around the clicked crop to harvest and replant. A value of `2` results in a 5×5 area.#### Behavior- Activates when right-clicking a fully-grown crop block.- Harvests and replants crops in the defined area.- Drops harvested items at the respective block positions.- Damages the item once for each crop harvested.- Only executes on the server side.#### Use Animation- **`BRUSH`** animation is played during use.---#### Example```json{  "ability_context": {    "area_harvest_ability": {      "cooldown": 20,      "min_hold": 0,      "max_hold": 72000,      "range": 2    }  }}```This configuration:- Applies a 1-second cooldown (20 ticks),- Instantly activates on right-click (no hold time),- Harvests a 5×5 crop area (range of 2).
