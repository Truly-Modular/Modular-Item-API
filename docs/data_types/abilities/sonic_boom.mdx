# Sonic Boom Ability

## Description

The `sonic_boom` ability fires a sonic boom beam that deals damage and applies knockback to all living entities within range, similar to the Warden's sonic boom attack. The ability only activates after the item has been held for a minimum number of ticks.### Fields- **`on_boom`** *(SoundEvent, default: `minecraft:entity.warden.sonic_boom`)*:    The sound event played when the sonic boom fires.- **`min_hold`** *(resolvable double, default: `15`)*:    Minimum number of ticks the item must be held before the ability activates on release.- **`damage`** *(resolvable double, default: `10`)*:    Damage dealt to each entity hit by the sonic boom.- **`cooldown`** *(resolvable double, default: `20`)*:    Cooldown applied to the item in ticks after the ability fires.- **`max_range`** *(resolvable double, default: `5`)*:    Maximum range in blocks around the player in which entities are affected.### Behavior- Activates when the player releases the item after holding it for at least `min_hold` ticks.- Hits all living entities (excluding the user) within a cube of radius `max_range`.- Deals `damage` using the sonic boom damage source, which bypasses shields.- Spawns `SONIC_BOOM` particles on each hit entity.- Plays the `on_boom` sound at the player's position.- Applies `cooldown` ticks of item cooldown after firing.- Only executes on the server side.### Use Animation- **`SPYGLASS`** animation is played while holding the item.---### Example```json{  "ability_context": [    {      "id": "addon:test",      "type": "miapi:sonic_boom",      "priority": 0,      "data": {        "on_boom": "minecraft:entity.warden.sonic_boom",        "min_hold": 15,        "damage": 10,        "cooldown": 20,        "max_range": 5      }    }  ]}```This configuration:- Requires holding for 15 ticks (0.75 seconds) before releasing,- Deals 10 damage to all entities within 5 blocks,- Applies a 1-second cooldown (20 ticks) after firing.
