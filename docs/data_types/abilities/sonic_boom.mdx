# Sonic Boom Ability

## Description

## SonicBoomAbilityThis ability allows items to emit a sonic boom attack, damaging nearby entities within a configurable range when used after a minimum hold time.### Features- Uses the `SPYGLASS` use animation.- Detects and damages living entities within a spherical area around the player.- Plays a configurable sound effect on activation.- Applies a cooldown after each use.- Only executes on the server side.- Creates sonic boom particle effects at each damaged entity.### Behavior- Player holds the item (right-click and hold).- On release after minimum hold time, the ability:  - Detects all living entities within the configured range.  - Deals damage to each entity.  - Plays the configured sound.  - Applies cooldown.  - Swings the used item hand.### JSON Context Fields- **`on_boom`** _(SoundEvent, optional, default = `SoundEvents.WARDEN_SONIC_BOOM`)_ :    The sound event played when the sonic boom activates.- **`min_hold`** _(number, optional, default = 15)_:    Minimum time in ticks the item must be held before the sonic boom triggers.- **`damage`** _(number, optional, default = 10)_:    Damage dealt to each entity within range.- **`cooldown`** _(number, optional, default = 20)_:    Time in ticks before the ability can be used again.- **`max_range`** _(number, optional, default = 5)_:    Radius in blocks for detecting and damaging entities.### Example```json{	"ability_context": [		{			"id": "addon:sonic_boom",			"type": "miapi:sonic_boom",			"data": {				"on_boom": "minecraft:entity.armor.equip_diamond",				"min_hold": 15,				"damage": 5,				"cooldown": 30,				"max_range": 3			}		}	]}```This configuration:- Plays a diamond armor equip sound on activation.- Requires 15 ticks of holding before triggering.- Deals 5 damage to entities within 3 blocks.- Applies a 30-tick cooldown.
