# Riptide Ability

## Description

The `riptide` ability replicates the vanilla trident Riptide enchantment effect, launching the player forward with a spin attack when the minimum hold time is met.This ability uses the **SPEAR** use animation and supports the following fields:### Fields- **`cooldown`** *(DoubleOperationResolvable, default: `20`)*:    Cooldown in ticks applied after the ability activates.- **`min_use`** *(DoubleOperationResolvable, default: `10`)*:    Minimum number of ticks the item must be held before the riptide launches on release.- **`spin_duration_base`** *(DoubleOperationResolvable, default: `20`)*:    Duration in ticks of the spin attack triggered on launch.- **`riptide_strength`** *(DoubleOperationResolvable, default: `20`)*:    Strength of the forward launch impulse. The base value is derived from the Riptide enchantment level (0, 1.5, 2.0, or 2.5); this resolvable is evaluated against that base value.- **`require_fluid`** *(boolean, default: `true`)*:    When `true`, the ability only activates when the player is in water, rain, or a bubble column. Set to `false` to allow activation anywhere.- **`custom_fluid`** *(fluid tag ResourceLocation, optional)*:    Overrides the default water/rain/bubble check. When provided, the player must be touching fluid belonging to this tag instead.- **`custom_sound`** *(ResourceLocation, optional)*:    Overrides the default riptide sounds (`trident.riptide_1/2/3`). The specified sound event will be played regardless of Riptide enchantment level.### Behavior- Activates when the player releases the item after holding it for at least `min_use` ticks.- The player must satisfy the fluid condition (see `require_fluid` / `custom_fluid`) at the time of release.- On activation, the player is launched in their look direction and enters a spin attack for `spin_duration_base` ticks.- If the player is on the ground at launch, an extra upward boost is applied (matching vanilla behaviour).- The item must not be fully damaged to activate.- Only executes on the server side.### Use Animation- **`SPEAR`** animation is played during use.---### Example```json{  "ability_context": [    {      "id": "addon:riptide",      "type": "miapi:riptide",      "priority": 0,      "data": {        "cooldown": 20,        "min_use": 10,        "spin_duration_base": 20,        "riptide_strength": 20,        "require_fluid": true      }    }  ]}```This configuration:- Applies a 1-second cooldown (20 ticks),- Requires the item to be held for at least 10 ticks before the launch triggers,- Runs a 20-tick spin attack on launch,- Uses a launch strength of 20,- Requires the player to be in water or rain (vanilla behaviour).
