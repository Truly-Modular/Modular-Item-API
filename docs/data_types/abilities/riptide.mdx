# Riptide Ability

## Description

## RiptideAbilityThis ability enables the Trident's **riptide effect**, allowing the player to be launched forward when using the trident while in water or rain.### Features- Launches the player forward when using the trident in water/rain.- Applies a configurable push strength based on riptide enchantment level.- Supports custom fluids (water, lava, or custom fluid tags).- Configurable spin attack duration.- Custom sound event on activation.- Requires minimum hold time before activation.- Applies cooldown after use.### Behavior- Player holds the trident (right-click and hold).- On release after minimum hold time:  - Checks if player is in water, rain, or a configured fluid.  - If conditions are met and the trident is not too damaged:    - Calculates push strength based on riptide enchantment level and configured modifiers.    - Launches the player forward.    - Applies a spin attack for the configured duration.    - Applies a ground jump boost if on ground.    - Plays the configured sound.  - If conditions are not met or trident is too damaged, does nothing.### JSON Context Fields- **`cooldown`** _(number, optional, default = 0)_:    Time in ticks before the ability can be used again.- **`min_use`** _(number, optional, default = 10)_:    Minimum time in ticks the item must be held before riptide activates. Vanilla is 10 ticks.- **`spin_duration`** _(number, optional, default = 0)_:    Duration of the spin attack in ticks. Enchantments add to this value.- **`riptide_strength`** _(number, optional, default = 0)_:    Base push strength multiplier. Each riptide enchantment level adds 1 (0, 1.5, 2.0, 2.5). A value of 0 prevents movement.- **`require_fluid`** _(boolean, optional, default = true)_:    If true, requires the player to be in a fluid (water, rain, or custom fluid).- **`fluid_overwrite`** _(string, optional)_:    Custom fluid tag to use instead of default water/rain. If not set, defaults to water and rain (setting this to water will remove rain).- **`custom_sound`** _(SoundEvent, optional)_:    Custom sound event to play on riptide activation. Defaults to player's riptide sound.### Example```json{	"ability_context": [		{			"id": "addon:custom_riptide",			"type": "miapi:riptide",			"data": {				"cooldown": 20,				"min_use": 10,				"spin_duration": 8,				"riptide_strength": 3,				"require_fluid": true,				"custom_sound": "minecraft:item.trident.riptide"			}		}	]}```This configuration:- Requires 10 ticks of holding before activation.- Applies a 3-level riptide strength (2.5 push).- Spins for 8 ticks.- Uses the default water/rain fluid requirement.- Plays the trident riptide sound.
