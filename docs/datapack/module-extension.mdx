# Module Extension

## Description

Module Extensions modify existing modules during the initial load AFTER inheritance by adding, overwriting, removing or merging properties.  Extensions are loaded from `mod-id:miapi/module-extensions/any-path-and-file-name.json`.  They can remove, replace or merge properties, similar to synergies.  - **remove** just destroyes all prior part of these properties - **replace** destroyes all prior info and adds this info instead - **merge** tries to non-destructivly add the additional data ontop of existing data, each property mreges data customThis is intended as a way to adjust existing modules, potentially in bulk via the tag-extensions.  If more conditions/control is requested, a Synergy might be better, as it is very similar in effect,  just instead of applying during load a Synergy applies live based on additional settable conditions.You can either set - `module` to target a single module- `tag` to target a Tag set by the ModuleTag property  ## Examples### Module Extension```json5{	id: 'miapi:super_blade',    //module id, they are resolved from the path of the target module tm_arsenal:miapi/modules/blade/normal.json will result in tm_arsenal:blade/normal as an ID	merge: {		//merges together, if it already has durability, it will be added together		material: 'miapi:metal/netherite',		durability: 2000	},	remove: [		//these properties will be fully removed from the module		'material_indication',		'model'	],	replace: {		//these properties will be replaced, ignoring previously existing data		tag: ['gem_armor', 'gem_armor_medium', 'gem_armor_generic', 'gem_armor_medium_generic']	}}```### Tag Extension```json5{	"tag": "chain_armor",	"merge": {		"material_indication": {			"hardness": {				"strength": 2,				"info": {					"type": "translatable",					"translate": "tm_armory.material_indication.default.armor_points",					"color": "dark_gray"				}			},			"flexibility": {				"strength": -1,				"info": {					"type": "translatable",					"translate": "tm_armory.material_indication.chain.flexibility",					"color": "dark_gray"				}			}		}	}}```
